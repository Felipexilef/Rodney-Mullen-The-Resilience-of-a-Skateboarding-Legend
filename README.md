# Rodney-Mullen-The-Resilience-of-a-Skateboarding-Legend
 Baseado na carreira do Skatista Rodney Mullen inovador do esporte, responsável pela criação do Ollie e do Flip. Com o objetivo de falar um pouco sobre suas metodologias no skate e sobre a sua evolução no esporte mesmo com problemas de saúde.
